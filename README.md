# ⚛️ NEUTRON
## A Gesture-Controlled Sci-Fi Energy Core Interface

> **"The future of human-computer interaction begins when machines understand intent, not instructions."**

NEUTRON is an experimental computer vision + real-time graphics project inspired by futuristic interfaces seen in science fiction.

The project transforms a simple webcam into an interactive control system where users can manipulate a digital energy core using natural hand gestures.

No controllers.
No physical input devices.
Only motion, gestures, and interaction.

---

## 🌌 Overview

NEUTRON is a futuristic gesture-based interface that combines:

- 🖐️ Real-time hand tracking
- 🧠 Computer vision
- ⚛️ Particle-based simulations
- 🎮 Gesture recognition
- 🌐 Interactive 3D graphics
- ✨ Sci-fi inspired visual effects

The goal of this project is to explore a simple question:

> **What if we could interact with digital objects the same way we interact with physical objects?**

Using a webcam, NEUTRON detects hand movements and translates them into real-time interactions with a dynamic energy core.

The user can:

- Compress and expand the energy core
- Rotate the core using hand movement
- Split the core into multiple energy entities
- Control multiple cores independently

---

# ✨ Features

## 🖐️ Natural Hand Interaction

NEUTRON uses real-time hand landmark detection to understand user gestures.

The system interprets:

- Hand position
- Finger openness
- Hand movement
- Two-hand distance
- Gesture states

and converts them into physical interactions.
